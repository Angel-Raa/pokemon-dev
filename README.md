# 📦 React & TanStack Query - Proyecto Pokémon

## 🚀 Configuración del entorno

### 1. Clonar el repositorio

Primero, clona este repositorio en tu máquina local con el siguiente comando:

```bash
git clone https://github.com/Angel-Raa/pokemon-dev.git
```

Luego, accede al directorio del proyecto:

```bash
cd pokemon-dev
```

### 2. Instalar dependencias

Este proyecto admite gestores de paquetes como **Bun**, **npm** o **yarn**. A continuación, se muestra cómo instalar las dependencias usando **Bun**:

```bash
bun install
```

> 💡 Si prefieres usar `npm` o `yarn`, asegúrate de eliminar el archivo `bun.lockb` para evitar conflictos.

### 3. Ejecutar el proyecto

Para iniciar el servidor de desarrollo, ejecuta:

```bash
bun run dev
```

Esto levantará la aplicación en modo desarrollo. Generalmente estará disponible en `http://localhost:3000`.
